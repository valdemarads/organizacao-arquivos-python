# organizacao-arquivos-python

Script em Python para automação da organização de arquivos por extensão.

## Descrição
Este projeto organiza automaticamente arquivos em um diretório, criando pastas de acordo com a extensão de cada arquivo.

## Tecnologias utilizadas
- Python 3
- Bibliotecas padrão: os, shutil

## Como usar
1. Execute o script `organizador_arquivos.py`
2. Informe o caminho da pasta que deseja organizar
3. Os arquivos serão movidos automaticamente para pastas por extensão
